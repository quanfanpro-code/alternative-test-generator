# 输入合同

## 余额表必需字段

| 字段 | 典型表头 | 说明 |
|------|----------|------|
| entity | 公司名称、被审计单位、核算单位 | 公司/账套标识 |
| counterparty | 供应商名称、客户名称、往来单位 | 对手方全称 |
| account_code | 科目代码、科目编码 | 科目编号 |
| account_name | 科目名称、会计科目 | 科目类别 |
| opening_balance | 期初余额、年初余额 | 可选，缺失时勾稽状态 NOT_RUN |
| ending_balance | 期末余额、年末余额 | 必需 |

## 序时账必需字段

| 字段 | 典型表头 | 说明 |
|------|----------|------|
| entity/ledger | 公司名称、账套、核算单位 | 公司/账套标识 |
| posting_date | 日期、记账日期、凭证日期 | 用于期间过滤 |
| voucher_type | 凭证类型、凭证种类 | 如"记账凭证" |
| voucher_no | 凭证号、凭证编号 | 凭证编号 |
| account | 科目名称、合计科目名称 | 会计科目 |
| debit | 借方金额、借方 | 借方金额 |
| credit | 贷方金额、贷方 | 贷方金额 |

## 可选字段

| 字段 | 典型表头 | 缺失行为 |
|------|----------|----------|
| line_no | 序号、行号 | 自动生成 |
| counterparty_aux | 辅助核算、供应商辅助核算 | 摘要中的名称只生成待确认候选 |
| summary | 摘要、业务说明、业务内容 | 限制度较低但不阻止生成 |
