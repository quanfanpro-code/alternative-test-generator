# 往来替代测试候选底稿生成器

保留内置负债方与资产方模板，读取实际余额清单和多年度序时账，生成汇总表和每个往来单位的明细底稿。

当前已实现：实际单位信息、按抽取数量插行、小计和比例公式、期后收付款候选、对方科目来源追踪、深海蓝等12种主题、保存前后验证与运行目录哈希校验。没有抽取规则时输出完整候选总体；检查结论不凭账簿自动填入。

AI优先自动识别和查证，正常流程无需用户编写参数或逐步审批。只有缺少关键事实或无法消除的实质歧义才集中询问。

- [技能说明](SKILL.md)：能力边界、自动执行原则和连续工作流程。
- [运行参数](references/运行参数.md)：AI使用的输入配置和命令入口。
- [输入字段](references/input-contract.md)：实际资料字段。

模板原件位于`assets/templates/`，生成只操作副本。不要把替换模板文件等同于适配另一种结构。

开发验证：在本目录用本机Python运行`-B -X utf8 -m pytest -p no:cacheprovider`。测试依赖包含pytest及仅用于构造旧XLS测试样本的xlwt；生产读取使用xlrd。
