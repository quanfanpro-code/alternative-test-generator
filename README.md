# 📋 往来替代测试候选凭证底稿生成器

> 把余额表和序时账丢进来，自动帮你找出可以做替代测试的凭证。但检查结论不替你填——你自己核查、自己做判断。

---

## 🎯 这个技能能干什么

审计实务里，发函证收不回来怎么办？**替代测试**——从序时账里找出收发凭证，逐笔检查合同、发票、入库单、付款记录，证明交易真实存在。

这个技能帮你把"找凭证"这一步自动化了。你需要做的只是：

1. 📥 上传余额表和序时账
2. ❓ 回答几个问题（期间、公司、科目方向、哪些供应商名字对不上）
3. 📄 拿到一张格式整齐的 Excel 底稿
4. 🔍 自己核查凭证，把检查结论填进去

**它不是替你下结论的——它是帮你整理数据、排版底稿的工具。**

---

## 🧠 整体逻辑（五步流水线）

```
📥 上传文件 → 🔍 自动探测 → ❓ 逐项提问 → 🍳 准备数据 → 📄 生成底稿 → ✅ 验证
```

每一步都有"停下来问你"的环节，你不点头它不往前走。不是全自动黑箱。

---

## 📋 第一步：你要准备什么东西

### 🔴 必须有的（缺一个跑不了）

| 🧾 材料 | 里面需要有什么 | 举个栗子 |
|---------|---------------|---------|
| **余额表** | 公司名字、供应商名字、科目类型、期末余额 | "合成采购有限公司，应付账款，期末余额 80 万" |
| **序时账** | 日期、凭证号、借方金额、贷方金额、摘要 | 今年每一笔凭证的借贷明细 |

### 🟡 没有也能跑的（但功能会打折）

| 材料 | 没有的后果 |
|------|-----------|
| 期初余额 | 勾稽这一步跳过，底稿里标"未执行" |
| 辅助核算列 | 匹配准确率降低，很多供应商名字对不上，只能靠摘要猜 |
| 你自己的模板 | 用系统内置标准模板生成 |

---

## 🔍 第二步：自动探测

你把文件拖进来，说一句"帮我生成替代测试候选凭证"，技能自动做：

1. 🕵️ **识别格式**——Excel、老版 XLS、CSV、制表符分隔的文本，全都认，不用你操心编码
2. 📊 **扫描工作表**——多个 Sheet 全部扫一遍，列出每张表的表头和行数
3. 🏷️ **猜测角色**——自动判断哪张像余额表（有关键词"期末余额""供应商"）、哪张像序时账（有"借方""贷方""凭证号"）
4. 🔗 **尝试匹配列名**——表里有一列叫"借方金额"，它就知道这是借方列

---

## ❓ 第三步：逐项问你（最关键）

探测完之后，一次只问一个问题。每问一个你答一个。

### 🗓️ 第一问：审计期间

"是哪一年哪个月到哪个月？"不会默认今年，必须你确认。

### 🏢 第二问：哪家公司

如果数据里有好几家实体，必须指定范围。

### 📋 第三问：确认角色

"我猜这张是余额表，对吗？"不对你可以纠正。

### 🗂️ 第四问：确认列名

"日期列我用了这一列、借方我用了这一列……你看对不对？"

### 📈 第五问：科目方向

这个科目余额正常在哪边？

- 应付账款、预收账款 → 通常在**贷方**
- 应收账款、预付账款 → 通常在**借方**

方向搞反了，后面的勾稽就全错了。

### 🔤 第六问：供应商名字对不上

这里是审计实务里最麻烦的一步。序时账里写的"合成采购"，余额表里是"合成采购有限公司"——名字不完全一样。

技能的处理规则：

- 🟢 **完全一样**（规范化之后）且只有一个 → 自动匹配，不需要问你
- 🟡 **缺了"有限公司"、有个括号差异、简称** → 列出来让你逐条确认
- 🔴 **怎么都对不上** → 留在"未匹配清单"，等你手动处理

> ⚠️ 它不会把"合成采购"静默匹配到"合成采购有限公司"，必须你点头。

### 🎯 第七问：抽样规则

你想挑哪些凭证？比如"大于 5 万的都要""前 20 笔"。

**没规则也无所谓**——技能会把全部符合条件的凭证列出来，叫"完整候选总体"，不替你挑。

### 📐 第八问：模板

有自己事务所的模板就上传，没有就用内置的。

---

## 🍳 第四步：准备数据

所有问题答完后，技能自动做三件事：

1. 🤝 **匹配供应商**——按你确认的结果
2. 🧮 **数学勾稽**——按公式算一遍：
   - 贷方科目：期初 + 本期贷方发生额 - 本期借方发生额 ＝ 期末？
   - 借方科目：期初 + 本期借方发生额 - 本期贷方发生额 ＝ 期末？
3. ⚠️ **报告差异**——数字对不上就告诉你差了多少，但不替你判断"是不是异常"

然后把结果展示给你看：
- 总共多少条候选凭证
- 自动精确匹配成功了几家
- 几家名字对不上需要你手动认
- 勾稽有没有差异

你确认没问题了，它才往下走。

---

## 📄 第五步：生成底稿

生成的 Excel 文件结构和一个标准审计底稿一模一样：

### 总览：一张汇总表 + 每个对手方一张明细 Sheet

| 📑 Sheet 名 | 里面有什么 |
|------------|-----------|
| 替代结果汇总表 | 所有供应商/客户的总览——索引号、名称、币种、原币金额、可确认金额、备注 |
| XX 公司 | 供应商/客户自己的明细，含三个板块 |
| YY 公司 | 同上 |
| ... | 每个对手方一张 |

### 每张明细 Sheet 的三板块结构

以负债方（应付账款）为例：

```
┌─────────────────────────────────────────────┐
│ 应付账款替代测试表                           │
│ 被审计单位:___ 编制:___ 日期:___ 索引号:___   │
├─────────────────────────────────────────────┤
│ 一、贷方发生额（正常采购入库）               │
│   检查材料：📦入库单 + 📄采购发票             │
│   序号│日期│凭证号│内容│科目│金额│            │
│       │    │      │    │    │    │入库单日期│数量│发票日期│数量│
│   数据行...                                   │
│   小计...                                     │
├─────────────────────────────────────────────┤
│ 二、借方发生额（付款冲销）                   │
│   检查材料：🏦银行回单 + 📎其他支持文件        │
│   同上结构                                    │
├─────────────────────────────────────────────┤
│ 三、期后付款                                 │
│   检查材料：🏦银行回单 + 📎其他支持文件        │
│   同上结构                                    │
├─────────────────────────────────────────────┤
│ 审计说明：（空，人工填写）                     │
└─────────────────────────────────────────────┘
```

资产方（应收账款）也一样，只是"贷方发生额"换成"借方发生额"，"期后付款"换成"期后收款"，检查材料换成 📤出库单 + 📄销售发票。

### 🔑 最重要：检查列全空

每行凭证旁边那些"入库单日期""入库单数量""采购发票日期""银行回单金额"……生成时**全部空白**。

这些都是你核查完原始凭证之后手动填的。技能不替你打勾，不替你写结论。

---

## 🔑 最重要的规则：结论必须你来写

"待核查底稿"这张表有四个检查列：

| 列 | 什么意思 | 生成时 |
|----|---------|--------|
| 📎 附件状态 | 合同、发票、入库单齐不齐 | 🔲 空 |
| ✅ 检查结果 | 核对结果 | 🔲 空 |
| ⚠️ 异常描述 | 有没有问题 | 🔲 空 |
| 📝 结论 | 最终判断 | 🔲 空 |

**生成时全部留空。** 它不会帮你打勾、不会写"附件完整"、不会写"未发现异常"。

怎么填？你**自己看过凭证、核对过附件、确认过审批之后**，告诉它"这行结论写什么"，它才填上去。你没说的，它不编。

---

## 🛑 什么情况会直接停

| 情况 | 为什么停 |
|------|---------|
| 文件坏了、加密了、根本不是表格 | 没法读 |
| 余额表里没有供应商名字或没有期末余额 | 核心字段缺失 |
| 借贷金额那列全是乱码 | 算不了 |
| 一个名字自动匹配到了两个不同供应商 | 会配错，不能继续 |
| 输出文件已经存在 | 不会覆盖你的老文件 |
| 你让它写"已检查"但没给检查证据 | 违反设计原则 |

## 🗣️ 怎么对话

不需要敲命令，直接说人话就行。

### 最简用法

> "帮我生成替代测试候选凭证，余额表和序时账我都上传了"

然后它会自动探测，一个一个问你。你答就行。

### 完整用法

> "这几家没回函，按我上传的模板整理应付和预付的候选凭证；供应商名字不一致的先问我，不要替我匹配"

它就会：
1. 发现名字有歧义的 → 列给你确认
2. 用你的模板排版
3. 应付按贷方、预付按借方分别算

### 无规则用法

> "抽样规则暂时没有，先把全部能用的凭证列出来"

它输出完整候选总体，不替你挑样本。

## ❓ 常见问题

**我只有期末余额没有期初余额，能用吗？**

能。勾稽步骤会标"未执行"，其他功能正常。

**序时账里没有供应商辅助核算列，只有摘要写了供应商名字，怎么办？**

会从摘要里提取名字片段生成候选，但准确率不高，建议你确认后再用。最好的做法是补充辅助核算列。

**我已经核查完了，想把结论写进底稿，怎么操作？**

告诉它"第几行结论是 XXX""这几条附件完整"，它会填进去。

**能不能批量处理多家公司的？**

能。逐个确认公司范围后，按公司分别生成。

**源文件会不会被改动？**

不会。所有输入文件只读不写，SHA-256 哈希校验保证原封不动。
